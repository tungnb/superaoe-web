Game không mở vì trình diệt virus xoá hoặc chặn file

SuperAqE chạy kèm một phần nhỏ (spec.dll) nạp vào game Đế Chế để nối phòng, cho khán giả xem và chạy replay. Một số trình diệt virus coi kiểu nạp này là đáng ngờ và cách ly file, khiến game không mở. Từ launcher 0.3.65, SuperAqE báo lỗi này bằng tiếng Việt và chỉ cách sửa ngay trong app. Cách làm với Windows Security (trình diệt virus có sẵn của Windows):

  1. 1

    Mở Lịch sử bảo vệ

    Mở Windows Security → Bảo vệ khỏi virus & mối đe dọa → Lịch sử bảo vệ, tìm mục liên quan tới SuperAoE.

  2. 2

    Khôi phục file

    Chọn mục đó, bấm Hành động → Khôi phục (hoặc Cho phép trên thiết bị).

  3. 3

    Thêm thư mục SuperAoE vào Loại trừ

    Bảo vệ khỏi virus & mối đe dọa → Quản lý cài đặt → Loại trừ → Thêm loại trừ → Thư mục. Bộ cài mặc định đặt SuperAoE ở %LOCALAPPDATA%\Programs\SuperAoE. Dùng trình diệt virus khác thì làm tương tự trong phần cách ly / ngoại lệ của nó.

  4. 4

    Mở lại game, vẫn lỗi thì cài lại

    Vẫn thiếu file thì tải lại SuperAoE-Setup.exe từ superaqe.com/download/setup và cài lại (sau khi đã thêm Loại trừ).

Chỉ loại trừ thư mục SuperAoE cài từ bộ cài tải ở superaqe.com, không loại trừ cả ổ đĩa.

Windows 11 chặn mở game (Smart App Control)

Smart App Control là tính năng của Windows 11 (thường bật sẵn trên máy mới cài) chặn mọi chương trình chưa có chữ ký số. SuperAqE và bản game đi kèm chưa có chữ ký số, nên khi tính năng này bật, Windows có thể từ chối mở game. Windows không cho bỏ qua riêng một ứng dụng, cách duy nhất là tắt: Windows Security → Kiểm soát ứng dụng & trình duyệt → Cài đặt Smart App Control → Tắt, rồi mở lại game.

Lưu ý trước khi tắt: sau khi tắt, Windows không cho bật lại Smart App Control (trừ khi cài lại Windows). Windows Security vẫn tiếp tục quét virus bình thường. Nếu không muốn tắt, bạn chưa chơi SuperAqE được trên máy đó.

Hỏi đáp

Câu hỏi thường gặp khi tải Đế Chế

Tải AoE 1 Rise of Rome ở đâu để chơi online?

Tải SuperAoE-Setup.exe tại superaqe.com/download/setup. Bộ cài đã có sẵn game Rise of Rome và launcher để chơi online miễn phí.

Đế Chế có chạy trên Windows 11 không?

Có. Gói SuperAqE dành cho Windows 10 và Windows 11, game đi kèm đã có cnc-ddraw để hiển thị đúng trên Windows đời mới.

Có phải cài đặt game không?

Không cần cài game riêng. Chỉ cần mở SuperAoE-Setup.exe, bấm cài một lần (không cần quyền quản trị) rồi mở SuperAqE từ biểu tượng trên Desktop.

Vì sao Windows cảnh báo khi mở SuperAoE-Setup.exe?

Bộ cài SuperAoE-Setup.exe chưa có chữ ký số, nên Windows SmartScreen cảnh báo như với nhiều ứng dụng mới. Bấm "Thông tin thêm" rồi "Vẫn chạy", và chỉ làm vậy với file tải từ superaqe.com.

Trình diệt virus xoá file, Đế Chế không mở được thì làm sao?

Mở Windows Security → Bảo vệ khỏi virus & mối đe dọa → Lịch sử bảo vệ, khôi phục file bị xoá, rồi thêm thư mục SuperAoE vào Loại trừ. Windows 11 bật Smart App Control thì phải tắt nó mới mở được game (tắt rồi không bật lại được). Chi tiết ở mục sửa lỗi phía trên.

Tải SuperAqE có mất phí không?

Không. Tải về, đăng ký tài khoản và chơi đều miễn phí.

Có bản cho MacBook không?

Có. SuperAqE có bản cài riêng cho MacBook chip Apple (M1, M2, M3, M4…), tải tại superaqe.com/download/mac (kèm Wine và game). Cách cài xem ở trang chơi AoE trên MacBook.
