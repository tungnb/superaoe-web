Chơi Đế Chế (AoE) trên Linux: bản SuperAqE cho Ubuntu, Mint, Debian, Fedora

Age of Empires 1 Rise of Rome là game Windows. Cách đơn giản nhất để chơi trên Linux là tải SuperAqE cho Linux: gói cài đã kèm Wine và game, không cần tự cài Wine, không cần sudo, tự cập nhật và chơi online chung phòng với người dùng Windows và Mac. Dành cho Linux 64-bit Intel/AMD (x86_64) có giao diện đồ họa. Miễn phí.

Cài bằng 1 lệnh Khuyên dùng

Bấm Ctrl + Alt + T để mở Terminal. Dán lệnh này rồi bấm Enter:

curl -fsSL https://superaqe.com/linux.sh | bash

Tự tải, cài vào thư mục nhà của bạn, thêm SuperAqE vào menu ứng dụng và màn hình rồi mở app. Không cần sudo. Gói khoảng 300 MB, vài phút.

Tình trạng

Bản SuperAqE cho Linux

  • Cách làm: gói SuperAqE chứa sẵn Wine (bản WoW64) và game Rise of Rome. Không cần cài Wine, không cần thư viện 32-bit, không cần cài Windows.
  • Máy dùng được: Linux 64-bit Intel/AMD (x86_64) có giao diện đồ họa: Ubuntu 22.04 trở lên, Linux Mint, Debian, Fedora…
  • Tải về: SuperAoE_Linux.tar.xz (khoảng 300 MB), hoặc cài thẳng bằng 1 lệnh Terminal (xem bên dưới).
  • Cài đặt: mở Terminal (Ctrl + Alt + T), dán lệnh curl -fsSL https://superaqe.com/linux.sh | bash rồi bấm Enter. Lệnh cài vào ~/.local/share/SuperAoE, thêm SuperAqE vào menu ứng dụng và biểu tượng trên màn hình rồi mở app. Không cần sudo.
  • Chơi game: lần đầu vào game mất khoảng 1 phút để chuẩn bị Wine. Game chạy 1366×768, toàn màn hình không viền.
  • Tự cập nhật: có bản mới, app tự cập nhật, không phải tải lại gói.
  • Xem lại trận: mọi trận online trên SuperAqE được tự lưu replay trên máy chủ. Xem cách xem lại trận AoE bằng replay.
  • Chơi chung: bản Linux dùng chung máy chủ, tài khoản và phòng với bản Windows và bản Mac.
  • Linux ARM: không hỗ trợ.

Tải SuperAqE cho Linux

SuperAqE có bản cho Windows 10/11, bản cho Mac chip Apple và bản cho Linux 64-bit. Nếu bạn dùng máy Windows, xem cách chơi AoE online miễn phí; dùng MacBook thì xem chơi AoE trên MacBook.

Cài đặt

Cài SuperAqE trên Linux

  1. 1

    Mở Terminal

    Bấm Ctrl + Alt + T (hoặc tìm Terminal trong menu ứng dụng).

  2. 2

    Dán lệnh cài, bấm Enter

    curl -fsSL https://superaqe.com/linux.sh | bash

    Lệnh tải gói khoảng 300 MB (vài phút tùy mạng), cài vào ~/.local/share/SuperAoE, thêm SuperAqE vào menu ứng dụng và biểu tượng trên màn hình rồi tự mở app. Không cần sudo, không cần cài Wine.

    Ubuntu báo không có curl? Cài trước bằng lệnh:

    sudo apt install curl
  3. 3

    Mở SuperAqE, đăng ký và vào phòng

    Lần sau mở từ menu ứng dụng, biểu tượng trên màn hình hoặc gõ lệnh superaoe. Lần đầu vào game mất khoảng 1 phút để chuẩn bị Wine. App tự cập nhật khi có bản mới.

Đã tải file tar.xz về rồi?

Mở Terminal ở thư mục chứa file vừa tải (thường là Tải về / Downloads) rồi làm theo:

  1. 1

    Giải nén SuperAoE_Linux.tar.xz

    tar -xJf SuperAoE_Linux.tar.xz

    Ra thư mục SuperAoE_Linux.

  2. 2

    Chạy file cài

    bash SuperAoE_Linux/install.sh

    SuperAqE được cài vào ~/.local/share/SuperAoE, có trong menu ứng dụng và trên màn hình.

  3. 3

    Mở SuperAqE

    Mở từ menu ứng dụng, biểu tượng trên màn hình hoặc lệnh superaoe. Trên GNOME (ví dụ Ubuntu), nếu biểu tượng trên màn hình chưa mở được thì bấm chuột phải vào nó, chọn Allow Launching.

Sửa lỗi

App không mở được vì thiếu thư viện

Bản Linux cài tối giản có thể thiếu vài thư viện hệ thống mà app cần. Trên Ubuntu, Linux Mint, Debian, cài chúng bằng lệnh:

sudo apt install libnss3 libgbm1 libgtk-3-0 libasound2 libxss1 libfreetype6 libgl1 libpulse0

Ubuntu 24.04 trở lên dùng tên gói mới:

sudo apt install libnss3 libgbm1 libgtk-3-0t64 libasound2t64 libxss1 libfreetype6 libgl1 libpulse0

Biểu tượng trên màn hình không mở được trên GNOME? Bấm chuột phải vào biểu tượng, chọn Allow Launching. Vẫn gặp lỗi: hỏi trong nhóm Facebook SuperAqE.

Hỏi đáp

Câu hỏi thường gặp về Đế Chế trên Linux

SuperAqE có bản cho Linux chưa?

Có. SuperAqE có bản cho Linux 64-bit (x86_64, Intel/AMD): tải tại đây. Gói đã kèm Wine và game, không cần cài Wine, không cần sudo, tự cập nhật trong app.

Bản Linux chạy trên bản phân phối nào?

Linux 64-bit Intel/AMD (x86_64) có giao diện đồ họa: Ubuntu 22.04 trở lên, Linux Mint, Debian, Fedora…

Có phải tự cài Wine hay thư viện 32-bit không?

Không. Gói đã kèm Wine (bản WoW64) nên không cần cài Wine hay thư viện 32-bit, và cài không cần sudo.

Người dùng Linux có chơi chung với Windows và Mac được không?

Được. Bản Linux dùng chung máy chủ, tài khoản và phòng với bản Windows và bản Mac.

Game chạy ở độ phân giải nào?

Trên Linux, game chạy 1366×768, toàn màn hình không viền. Lần đầu vào game mất khoảng 1 phút để chuẩn bị Wine.

Máy Linux ARM (Raspberry Pi…) có chơi được không?

Không. Bản Linux chỉ dành cho máy 64-bit Intel/AMD (x86_64); Linux ARM không được hỗ trợ.

App không mở được vì thiếu thư viện thì làm sao?

Trên bản cài tối giản có thể thiếu thư viện. Trên Ubuntu/Debian chạy sudo apt install libnss3 libgbm1 libgtk-3-0 libasound2 libxss1 libfreetype6 libgl1 libpulse0 (Ubuntu 24.04 trở lên thay libasound2 bằng libasound2t64 và libgtk-3-0 bằng libgtk-3-0t64). Xem phần sửa lỗi.
